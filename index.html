Cybersecurity Terms & Policies

Comprehensive cybersecurity terminology, policies, and best practices.

Core Security Principles

CIA Triad

Confidentiality, Integrity, Availability — the foundation of information security.

AAA Model

Authentication, Authorization, Accounting (Auditing) — verify, permit, and track user actions.

Zero Trust

Never trust, always verify. Every access request is authenticated and authorized.

Common Cybersecurity Terms

MalwareMalicious software including viruses, worms, trojans, ransomware, and spyware.
PhishingFraudulent attempts to obtain sensitive information via email, SMS, or voice.
Social EngineeringPsychological manipulation to trick users into making security mistakes.
SQL InjectionCode injection technique that exploits database vulnerabilities.
XSSCross-Site Scripting — injecting malicious scripts into web pages.
DDoSDistributed Denial of Service — overwhelming a system with traffic.
MITMMan-in-the-Middle — intercepting communication between two parties.
Zero-DayA vulnerability unknown to the vendor, with no patch available.
RansomwareMalware that encrypts data and demands payment for decryption.
RootkitMalicious software that hides its presence and provides privileged access.
BotnetA network of infected devices controlled by an attacker.
KeyloggerRecords keystrokes to capture passwords and sensitive information.
APTAdvanced Persistent Threat — prolonged, targeted cyberattack.
Insider ThreatSecurity risk originating from within the organization.
Data BreachUnauthorized access to sensitive data.
Penetration TestingAuthorized simulated attack to identify vulnerabilities.

Security Controls

Preventive

Firewalls, encryption, MFA, access controls — stop attacks before they happen.

Detective

IDS, SIEM, monitoring, audits — identify and alert on security incidents.

Corrective

Patching, incident response, backups, recovery — restore and remediate after incidents.
